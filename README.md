# Clube Cooperado de Sítios

## Propósito do Produto

Criar um app estilo Tinder + Airbnb, onde o usuário seleciona o sítio ideal a partir de preferências e filtros, e o match libera o contato direto com o proprietário via WhatsApp.

Não há intermediação.

Todos os sítios pagam uma mensalidade fixa para fazer parte do clube de propaganda coletiva.

## Públicos Principais

- **Hóspedes**: pessoas buscando sítios para alugar.
- **Proprietários**: sítios que fazem parte do clube cooperado.
